# Income and Expense Tracker App

It is a web application to track incomes and expenses, with data saved in the browser using localStorage.

The project is for learning purposes only.

## 🎯 Goal

- Practice React fundamentals
- Manage application state
- Work with browser localStorage
- Build a simple budget management app

## 🛠️ Technologies

- React
- Bootstrap
- JavaScript
- localStorage

## 📱 Features

- Add incomes and expenses
- Save data using localStorage
- View a list of transactions
- Simple balance calculation
